# Pyerite data deletion

Pyerite does not create accounts and does not keep player data on a developer server. This page explains how to delete data stored by the Pyerite app.

## Delete data in the app

1. Open Pyerite.
2. Open Character Management (角色管理).
3. Tap Edit (编辑).
4. Tap the delete icon beside the character.
5. Tap Remove (移除).

This takes effect immediately. Pyerite does not keep a copy after you confirm.

## Data that is deleted

- Character name and character ID stored in the app
- EVE login token for that character, which is also revoked
- That character's game data cached in the app, such as skills, mail, wallet, and assets

## Data that is not deleted

- Your EVE Online account. Pyerite cannot delete an account managed by Fenris Creations.
- Mail or other data already sent to EVE Online. That data remains with EVE Online.
- The item database downloaded by the app. It is not personal data.
